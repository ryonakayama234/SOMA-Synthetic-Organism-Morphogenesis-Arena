# F001 — 単一セルが動く（仕様案・未実装）

## 問い
一個のロボット細胞に力を与えたとき、位置と速度の変化を再現可能に計測できるか。

## 仮説 H001
一定方向の力を与えた細胞は、その方向に移動する。力を加えないとき、静止している細胞は移動しない。抵抗のある環境では力を止めたあと速度が減少する。

**対立仮説／失敗例**：無入力でも移動する／符号反転に応じて方向が反転しない／抵抗だけで速度が増す／刻みを細かくすると挙動が大きく変わる。

## 今回作る能力
- **一個のセルが水平1次元で運動する**。最初に複雑な形状や3Dレンダリングは不要。
- 制御入力は外部からの一つの力（N）。
- 位置と速度を時間の関数として保存する。
- これを実現するまで学習・合体・エネルギー・複数セル・資源は**追加しない**。

## 計算モデル（最初の近似であって、完成した物理ではない）
質量 m > 0 [kg]、速度 v [m/s]、入力 F [N]、線形抵抗率 gamma >= 0 [1/s]：
m dv/dt = F - m gamma v,   dx/dt = v.

時間刻み dt [s] の半陰的Euler法：
v_next = v + dt * (F/m - gamma*v)
x_next = x + dt * v_next

※線形抵抗は比較用の簡易モデルで、接地摩擦や剛体接触を忠実に再現するものではない。後の研究で変更可能。

## 実験計画（対照群）
| 条件 | 力 | 初速 | 予測 |
| --- | ---: | ---: | --- |
| A 静止対照 | 0 N | 0 m/s | 位置・速度は変化しない |
| B 正方向 | +1 N | 0 m/s | 正方向へ進む |
| C 逆方向 | -1 N | 0 m/s | Bと対称の負方向へ進む |
| D 減速 | 0 N | +1 m/s | gamma > 0 なら速度は減衰 |
| E 分割刻み | Bと同条件 | 0 m/s | dtを半分にして結果を比較 |

m=1 kg, gamma=0.2 1/s, dt=0.01 s, 各10 sを出発点として提案。条件値は実装時に設定ファイルとして確定し、固定する。

## 成功・受入条件
1. Aで全ステップの x=v=0 が保持される（許容誤差 1e-12）。
2. BとCの軌跡は符号反転の対称性を満たす（絶対誤差 1e-9、同じ刻み）。
3. Dで速度は非増加かつ負にならない（dt*gamma <= 1 の条件内）。
4. Eで dt=0.01 と 0.005 の最終位置の差分を記録し、刻みをさらに半分にした場合の収束傾向も報告する。**任意の閾値で適合したふりをしない**。
5. 全runに設定・バージョン・CSV・簡単なグラフを紐づける。
