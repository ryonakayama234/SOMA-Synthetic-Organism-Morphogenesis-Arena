# F001 — 単一セルが動く（実装済み・初回数値実験検証済み）

## 問い
一個のロボット細胞に力を与えたとき、位置と速度の変化を再現可能に計測できるか。

## 仮説 H001
一定方向の力を与えた細胞は、その方向に移動する。力を加えないとき、静止している細胞は移動しない。抵抗のある環境では力を止めたあと速度が減少する。

**対立仮説／失敗例**：無入力でも移動する／符号反転に応じて方向が反転しない／抵抗だけで速度が増す／刻みを細かくすると挙動が大きく変わる。

## 今回作る能力
- **一個のセルが水平1次元で運動する**。最初に複雑な形状や3Dレンダリングは不要。
- 制御入力は外部からの一つの力（N）。
- 位置と速度を時間の関数として保存する。
- これを実現するまで学習・合体・エネルギー・複数セル・資源は**追加しない**。

## 計算モデル（最初の近似であって、完成した物理ではない）
質量 m > 0 [kg]、速度 v [m/s]、入力 F [N]、線形抵抗率 gamma >= 0 [1/s]：
m dv/dt = F - m gamma v,   dx/dt = v.

時間刻み dt [s] の半陰的Euler法：
v_next = v + dt * (F/m - gamma*v)
x_next = x + dt * v_next

※線形抵抗は比較用の簡易モデルで、接地摩擦や剛体接触を忠実に再現するものではない。後の研究で変更可能。

## 実験計画（対照群）
| 条件 | 力 | 初速 | 予測 |
| --- | ---: | ---: | --- |
| A 静止対照 | 0 N | 0 m/s | 位置・速度は変化しない |
| B 正方向 | +1 N | 0 m/s | 正方向へ進む |
| C 逆方向 | -1 N | 0 m/s | Bと対称の負方向へ進む |
| D 減速 | 0 N | +1 m/s | gamma > 0 なら速度は減衰 |
| E 分割刻み | Bと同条件 | 0 m/s | dtを半分にして結果を比較 |

m=1 kg, gamma=0.2 1/s, dt=0.01 s, 各10 sを出発点として提案。条件値は実装時に設定ファイルとして確定し、固定する。

## 成功・受入条件
1. Aで全ステップの x=v=0 が保持される（許容誤差 1e-12）。
2. BとCの軌跡は符号反転の対称性を満たす（絶対誤差 1e-9、同じ刻み）。
3. Dで速度は非増加かつ負にならない（dt*gamma <= 1 の条件内）。
4. Eで dt=0.01 と 0.005 の最終位置の差分を記録し、刻みをさらに半分にした場合の収束傾向も報告する。**任意の閾値で適合したふりをしない**。
5. 全runに設定・バージョン・CSV・簡単なグラフを紐づける。

## 今回のデータ
設定: mass_kg, drag_per_s, force_n, dt_s, duration_s。
時系列: time_s, x_m, v_m_s, force_n。
詳しくは [データの約束](../../docs/DATA_CONTRACTS.md)。

## 研究記録（2026-10-13）
- 実行：Python 3.13の作業コピーでA〜E（6条件）を実行。
- 結果：Aは静止、B/Cは符号対称、Dは減速、Eの位置誤差は刻み半減で約半減。
- 検証：自動テスト9件合格、連続時間の解析解およびWolfram Languageの独立計算と整合。
- 仮説判定：今回の条件では支持。実機挙動・身体創発を示すものではない。
- 誤差・再現条件：[初回検証ノート](../../findings/F001-validation.md) と [実験手順](../../experiments/F001/README.md)。
- 制約：現状1D/線形粘性抵抗の玩具モデル。将来の接触・結合に直接一般化しない。

## 解析解の有限値回帰検証（PR #5、2026-10-14）

極小抵抗での桁落ちに加え、抵抗のある解析解で大きな数値を掛け合わせる途中の浮動小数点オーバーフローを修正した。計算結果が有限でも`a*t*t`や`a*t`が先に`inf`となるため、仮数と指数を分離した積に置換する。Wolframによる独立基準値と比較するテストを、正負の巨大な外力、強い抵抗、微小力・非常に長い時間に追加した。PR #5のコード・テストコミット`7befcfb4`に対する[CI #38547923781](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/actions/runs/38547923781)は15テスト合格。旧A〜Eの実験条件や物理モデルは変更せず、[研究記録](../../findings/F001-validation.md)に追加検証を独立して追記した。初回の9件および当時の観測結果は履歴として残す。
