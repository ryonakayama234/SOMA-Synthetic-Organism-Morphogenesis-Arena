# F007 — 誰の電池で、結合した二つのセルが動くのか？

> **設計のみ・未実装・未実験・未採用。** この文書の予測値はWolframでの独立した離散モデル計算であり、SOMAの実行結果ではない。

[Issue #19](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/19) / [事前実験計画](../../experiments/F007/PLAN.md) / [検証記録（未実施）](../../findings/F007-validation.md)

## 目的と一能力の境界

既存のF003（2セル理想1Dリンク）、F005（1セルの正モーター仕事）、F002（整数µJ台帳）を**片側Aのみのモーター**という一つの場面で整合させる。結合されたBが動けるとしても、その原因をAの有効駆動力と理想リンクの力伝達で説明し、Bの電池を勝手に使わない。結合を採点・優遇するルールは追加しない。

* **対象**：2セルA/B、固定質量・共通drag係数、リンクON/OFFと既存の時刻指定切断、Aのモーター指令、各セルへの独立な外部指定力、セル別F002残高。
* **非対象**：自律的な結合判断、局所観測、身体構造推論、セル間の電気エネルギー移送、資源獲得、接触/摩擦による実推進、実機、学習/進化、形態の優劣。
* **整合性の優先**：F001〜F006の採用済みAPIと過去ログを改変しない。F007は新規の薄い結合層として検証する。外部有効駆動力の背後にある地面反力は未定義なので、自由空間で推進する「内力」だとは主張しない。

## 問いと仮説

**Q007**：片方の電池だけで与えた有効駆動力によって、結合された非駆動セルの運動は変わるか。誰に機械仕事と電池支出を帰属させるべきか。

**H007a — 運動・作用反作用**：結合したときは共通速度で動き、Aへの有効駆動力はBにも理想リンクを通じて伝達される。非結合Bには力が伝わらない。リンク内部力の和はゼロで、Bに仕事が移っても電気エネルギーが転送されたことにはならない。

**H007b — 所有と拒否**：Aの正モーター仕事だけをAのF002残高から支出し、Bの残高は不変。残高不足ならその刻みでは**Aのモーターだけを拒否し**、A/B外力とリンクはそのまま適用し直す。指令力と実際に作用した力は別フィールドで記録する。

**H007c — 既存機能の合成可能性**：中途切断では位置・速度の瞬間ジャンプがなく、接続中はF003の合成質量、切断後は独立した質量でAの正仕事が再計算される。F005の正仕事・F002のinteger-µJ意味論を保つ。

**反証条件**：非結合Bの加速、リンク力の非相殺、外力をA電池へ誤請求、B電池の不意な減少、電池不足時にAの指令を適用、切断瞬間の速度跳躍、不正入力からの正常ログ生成、保存ログ改変の検証すり抜け。結果がdtに敏感であればそれ自体を記録し、結合利益の主張は保留する。

## 最小モデル：設計方針（実装ではない）

各区間の開始時点でAの候補モーター力 `u_A` と外力 `f_A,f_B` を区別する。リンクONなら合成質量 `M=m_A+m_B`、合計有効力 `u_A+f_A+f_B` と共通速度を用いてF003型の候補更新を計算。OFFならAの `u_A+f_A` とBの `f_B` で独立更新する。

Aの正仕事 `W_A^+=∫max(0,u_A*v_A(t))dt` はF005の**線形区間速度補間**で定義し、費用を `ceil(10^6 W_A^+)` µJとしてAの残高と比較。十分な場合のみAの候補モーターを採用・台帳へ支出し、不足なら `u_A=0` として**運動・リンク力・仕事をすべて再計算**。新たな実装ではF005の演算順・underflow/rounding境界を回帰検証し、再解釈して仕様を変えない。

リンクがONでA/Bの速度が共通なら、内部リンク力の瞬時パワーは `T_A*v + T_B*v=0`。これは「リンク内部では相殺する」という数学であり、各セル間に個別の電池移送イベントを発生させる理由にはならない。リンクの強度制限・構造物の疲労・接触反力は未定義。

**離散モデルの境界**：F003の半陰的Eulerの位置更新とF005の区間内速度補間による仕事積分は異なる軌道概念。保持/待機損失なし、回生なし、1µJごとの各ステップ切上げ、all-or-nothing拒否のdt依存はF006で既知。F007採用は現実の移動効率比較・生存条件比較への許可を意味しない。

## 事前の数理参照

Wolfram Languageで有理数として独立計算（**実験結果ではない**）：`m_A=m_B=1kg`、`u_A=+2N`、`f_A=f_B=0`、`drag=0`、`dt=1/4s`、4区間、`L=1/2m`、初期速度0、Aの初期残高3,000,000µJ、B残高0。予測は次のとおり。

| --- | ---: | ---: |
| 終速度 v_A [m/s] | 2 | 1 |
| 終速度 v_B [m/s] | 0 | 1 |
| Aの半陰的Euler変位 [m] | 5/4 | 5/8 |
| Bの半陰的Euler変位 [m] | 0 | 5/8 |

結合の有利不利は上表から判定しない。運べるBの質量が増す代わりに速度・変位とAの消費が変わるだけである。連続力学の変位と半陰的Euler離散位置は同じではない。
