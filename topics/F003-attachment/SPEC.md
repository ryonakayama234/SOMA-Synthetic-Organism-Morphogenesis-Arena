# F003 — 結合により何が変わるのか（仕様案・未実装）

[追跡 Issue #3](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/3) / [実験計画](../../experiments/F003/PLAN.md)

## 研究上の問いと境界
二つの同型セルが、外部から与えられた力で独立に移動するときと、理想的な剛体リンクで接続されたときでは、運動・力の分担・切断後の運動がどう変化するか。

**今回の能力は「一次元・二セル・理想リンクのON/OFF」だけ**。結合の自律的選択、接続の物理機構、衝突、回転、通信、エネルギー伝送、学習、生存、創発を扱わない。「結合すると有利」という報酬・補正を加えない。

世界の接続真値は実験計測器のみに提供する。セルの知覚・行動制御器はF003ではまだ作らず、外部から決めた駆動力を与える。

## 仮説 H003
- H003a：未結合でAのみを駆動すると、AはF001に従い、Bには力が伝わらない。
- H003b：結合中は二セルが共通速度となる。等質量・片側駆動では、単体Aよりも加速度が小さくなるが、非駆動Bが同時に移動する。これを「利益」とは決めつけない。
- H003c：切断の瞬間に位置・速度は飛ばず、その後の各セルが独立のF001運動に戻る。

**代替・反証**：力がないのに動く／結合がないのにBが加速する／内部結合力の和がゼロでない／結合中に距離・速度拘束が崩れる／切断時に位置・速度が飛ぶ／時間刻みを変えても数値誤差の傾向を説明できない。

## 最小力学モデル
各セルはF001に準じる質量 m_i [kg]、位置 x_i [m]、速度 v_i [m/s]、外力 F_i [N]、線形抵抗率 gamma [1/s]を持つ。二セルの gamma は同じ設定値。リンク長 L [m] は正の固定値で、リンクは質量を持たず、一次元の拘束のみを表す。

未結合：各セルは m_i dv_i/dt = F_i - m_i gamma v_i、dx_i/dt = v_i として独立に更新する。

結合中：x_B - x_A = L、v_A = v_B = v。M=m_A+m_B、F_total=F_A+F_B とすると
- M dv/dt = F_total - M gamma v
- dx_A/dt = dx_B/dt = v
- Bに作用するリンク力 T_B = m_B F_total/M - F_B [N]
- Aに作用するリンク力 T_A = -T_B [N]

内部力は合計ゼロ。F001同様、半陰的Eulerを用いる方針。ただし数値実装では距離拘束を壊す丸め・時間更新に注意し、共有変位を各セルに適用する。

**結合開始の前提**：リンク長に整合する位置関係と等しい速度が必要。条件外の「瞬間結合」は黙って位置・速度を修正せず、明示的に拒否する。衝突時の結合や衝撃力は将来の別能力。

切断時は、その時点の位置・速度をそのまま二つの独立状態へ引き継ぐ。架空のインパルス、瞬間的な位置調整は与えない。

## 基準条件（実験結果ではない）
同型セル m_A=m_B=1 kg、gamma=0.2 1/s、L=0.5 m、初速0、F_A=1 N、F_B=0 N、dt=0.01 s、10 s。連続系の理論値は結合状態で共通速度約 2.16166179 m/s、共有変位約 14.19169104 m。未結合Aの変位は約 28.38338208 m（F001）。**これらは解析式の理論予測で、SOMAコードの実測ではない。** 2026-10-14にWolfram Languageでリンク力式、gamma→0極限とともに独立検算した。半陰的Eulerの離散値には時間刻みに応じた誤差がある。

## 必須不変条件／受入条件
1. 未結合二セルそれぞれの時系列が、同条件のF001参照計算と一致する。
2. 結合中の速度差と距離拘束誤差は、事前に定める浮動小数点許容値の範囲内である。
3. 各時点の内部力の和はゼロ、かつ重心の運動が外力合計・抵抗と一致する。
4. 切断直前／直後に位置・速度の瞬間変化を導入しない。
5. 符号反転対称性、dt半減時の理論値への誤差変化、非有限値・不整合接続の拒否を確認する。
6. 初期条件・単位・実行コードコミット・生ログ・図・否定的結果が追跡可能。

判定：支持／反証／不明／未実施を条件別に記録。現時点は**未実施**。観測できるのは理想化した1D力学モデルの内部整合性までであり、物理的コネクタの実現性・身体の創発はまだ示せない。

## 実装担当の裁量と非目標
実装ファイル名・クラス分割は必要に応じて決めてよいが、既存F001の計算・テストを破壊しない。F002の実装・レビューPRに依存せず、別ブランチ・別PRで変更する。学習器や3D物理エンジンを持ち込まない。第三者視点のレビューで対照群・式・ログ・実装境界を監査してから採用判断する。

## 観測前に固定する受入規約（2026-10-15）

- **イベント順序**：初期接続は時刻0だけ。切断時刻は`0 < t < duration_s`かつ`dt_s`の整数倍に限定する。時刻tで記録された状態の位置・速度を一切変えずに切断し、その後の区間(t,t+dt]を非結合として計算。刻みに合わない要求は暗黙に丸めず拒否する。
- **参照系**：非結合時は各セルのF001半陰的Euler計算、結合時は質量合計と外力合計を代入したF001型計算を別々のオラクルとして比較する。連続解析解との誤差はそれらと区別する。
- **名目実験A〜Fの数値不変条件**：結合中`|x_B-x_A-L| ≤ 1e-10 m`、`|v_B-v_A| ≤ 1e-12 m/s`、`|T_A+T_B| ≤ 1e-12 N`。初期座標が桁外れに大きい条件への保証ではない。
- **切断の連続性**：同じ時刻のイベント前後で`Δx_A=Δx_B=Δv_A=Δv_B=0`を確かめる。`states.csv`は原則1時刻1行で、ON→OFFは`events.csv`に別記する。
- **刻み収束**：Bの`dt=0.01/0.005/0.0025 s`で解析値に対する位置・速度誤差が単調減少し、隣接する位置誤差比がおおむね`1.8～2.2`であることを事前予測する。外れた場合も値を保存し分析する。
- 理想リンクの張力・圧縮力に強度上限を置かず、衝突、接触、電力消費、実機コネクタを扱わない。成立したのは力学ソフトウェアの整合性に限られ、創発の証拠ではない。
