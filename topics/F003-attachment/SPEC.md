# F003 — 結合により何が変わるのか（実装候補・正式採用前）

[追跡 Issue #3](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/3) / [実験計画](../../experiments/F003/PLAN.md)

## 研究上の問いと境界
二つの同型セルが、外部から与えられた力で独立に移動するときと、理想的な剛体リンクで接続されたときでは、運動・力の分担・切断後の運動がどう変化するか。

**今回の能力は「一次元・二セル・理想リンクのON/OFF」だけ**。結合の自律的選択、接続の物理機構、衝突、回転、通信、エネルギー伝送、学習、生存、創発を扱わない。「結合すると有利」という報酬・補正を加えない。

世界の接続真値は実験計測器のみに提供する。セルの知覚・行動制御器はF003ではまだ作らず、外部から決めた駆動力を与える。

## 仮説 H003
- H003a：未結合でAのみを駆動すると、AはF001に従い、Bには力が伝わらない。
- H003b：結合中は二セルが共通速度となる。等質量・片側駆動では、単体Aよりも加速度が小さくなるが、非駆動Bが同時に移動する。これを「利益」とは決めつけない。
- H003c：切断の瞬間に位置・速度は飛ばず、その後の各セルが独立のF001運動に戻る。

**代替・反証**：力がないのに動く／結合がないのにBが加速する／内部結合力の和がゼロでない／結合中に距離・速度拘束が崩れる／切断時に位置・速度が飛ぶ／時間刻みを変えても数値誤差の傾向を説明できない。

## 最小力学モデル
各セルはF001に準じる質量 m_i [kg]、位置 x_i [m]、速度 v_i [m/s]、外力 F_i [N]、線形抵抗率 gamma [1/s]を持つ。二セルの gamma は同じ設定値。リンク長 L [m] は正の固定値で、リンクは質量を持たず、一次元の拘束のみを表す。

未結合：各セルは m_i dv_i/dt = F_i - m_i gamma v_i、dx_i/dt = v_i として独立に更新する。

結合中：x_B - x_A = L、v_A = v_B = v。M=m_A+m_B、F_total=F_A+F_B とすると
- M dv/dt = F_total - M gamma v
- dx_A/dt = dx_B/dt = v
- Bに作用するリンク力 T_B = m_B F_total/M - F_B [N]
- Aに作用するリンク力 T_A = -T_B [N]

内部力は合計ゼロ。F001同様、半陰的Eulerを用いる方針。ただし数値実装では距離拘束を壊す丸め・時間更新に注意し、共有変位を各セルに適用する。

**結合開始の前提**：リンク長に整合する位置関係と等しい速度が必要。条件外の「瞬間結合」は黙って位置・速度を修正せず、明示的に拒否する。衝突時の結合や衝撃力は将来の別能力。

切断時は、その時点の位置・速度をそのまま二つの独立状態へ引き継ぐ。架空のインパルス、瞬間的な位置調整は与えない。

## 基準条件（実験結果ではない）
同型セル m_A=m_B=1 kg、gamma=0.2 1/s、L=0.5 m、初速0、F_A=1 N、F_B=0 N、dt=0.01 s、10 s。連続系の理論値は結合状態で共通速度約 2.16166179 m/s、共有変位約 14.19169104 m。未結合Aの変位は約 28.38338208 m（F001）。**これらは解析式の理論予測で、SOMAコードの実測ではない。** 2026-10-14にWolfram Languageでリンク力式、gamma→0極限とともに独立検算した。半陰的Eulerの離散値には時間刻みに応じた誤差がある。

## 必須不変条件／受入条件
1. 未結合二セルそれぞれの時系列が、同条件のF001参照計算と一致する。
2. 結合中の速度差と距離拘束誤差は、事前に定める浮動小数点許容値の範囲内である。
3. 各時点の内部力の和はゼロ、かつ重心の運動が外力合計・抵抗と一致する。
4. 切断直前／直後に位置・速度の瞬間変化を導入しない。
5. 符号反転対称性、dt半減時の理論値への誤差変化、非有限値・不整合接続の拒否を確認する。
6. 初期条件・単位・実行コードコミット・生ログ・図・否定的結果が追跡可能。

判定：支持／反証／不明／未実施を条件別に記録。事前登録時点は**未実施**。現行候補の実測はfindingsを参照。観測できるのは理想化した1D力学モデルの内部整合性までであり、物理的コネクタの実現性・身体の創発はまだ示せない。

## 観測前に固定する受入規約（2026-10-15）

- **イベント順序**：初期接続は時刻0だけ。切断時刻は`0 < t < duration_s`かつ`dt_s`の整数倍に限定する。時刻tで記録された状態の位置・速度を一切変えずに切断し、その後の区間(t,t+dt]を非結合として計算。刻みに合わない要求は暗黙に丸めず拒否する。
- **参照系**：非結合時は各セルのF001半陰的Euler計算、結合時は質量合計と外力合計を代入したF001型計算を別々のオラクルとして比較する。連続解析解との誤差はそれらと区別する。
- **名目実験A〜Fの数値不変条件**：結合中`|x_B-x_A-L| ≤ 1e-10 m`、`|v_B-v_A| ≤ 1e-12 m/s`、`|T_A+T_B| ≤ 1e-12 N`。初期座標が桁外れに大きい条件への保証ではない。
- **切断の連続性**：同じ時刻のイベント前後で`Δx_A=Δx_B=Δv_A=Δv_B=0`を確かめる。`states.csv`は原則1時刻1行で、ON→OFFは`events.csv`に別記する。
- **刻み収束**：Bの`dt=0.01/0.005/0.0025 s`で解析値に対する位置・速度誤差が単調減少し、隣接する位置誤差比がおおむね`1.8～2.2`であることを事前予測する。外れた場合も値を保存し分析する。
- 理想リンクの張力・圧縮力に強度上限を置かず、衝突、接触、電力消費、実機コネクタを扱わない。成立したのは力学ソフトウェアの整合性に限られ、創発の証拠ではない。

## イベント記録・拒否処理と定量受入基準の確定（2026-10-15、実装・観測前）

この節はPR #7の事前登録規約であり実装・実験結果ではない。H003a〜c、名目条件A〜F、既存の誤差許容値を維持する。

### 決定1：切断時刻の状態スナップショット
- 内部時間は整数ステップ番号kを使い、出力時刻は k * dt_s とする。duration_s/dt_s と detach_time_s/dt_s は十進表現で整数となる入力のみ受理し、暗黙に丸めない。
- 各区間 (t[k-1], t[k]] の運動をその区間開始時の結合状態で更新する。切断イベントは区間終端t[k]で適用し、位置・速度は変更せず結合フラグだけtrueからfalseにする。次の区間から独立運動。
- states.csvは**同時刻のイベント反映後の真値を1時刻につき1行**保存する。切断時刻t=5の行はattached=false、リンク力A/B=0 N、拘束誤差欄は空欄（OFFでは拘束が存在しない）。
- events.csvのdetach行にはtime_s、kind、attached_before、attached_after、各セルのx/vのbeforeとafter、link_force_before_nを格納する。4組のx/vのbeforeとafterは同じ値のままコピーし、瞬間的な位置・速度補正・インパルスは発生させない。初期接続がある場合は検証済みのattach_initialをt=0に記録する。

### 決定2：不正な設定の拒否と記録
- ワールド生成・正常run出力の作成より前に、非有限値、非正の質量、初期距離不整合、初速不整合、時刻が範囲外／刻みと不整合な切断要求を検査する。問題を黙って修正せず、理由を持つ例外として拒否する。
- events.csvは**正常runで発生した結合・切断**だけを記録する。不正な実験設定は実行されていないため混ぜない。
- F実験のスイートで、rejections.jsonへ各case_id、入力条件、expected_error、actual_error、reason、rejected_before_run、passを保存する。不正な入力で正常runのディレクトリが作成された場合は不合格。
- rejections.jsonとテスト判定スクリプトのSHA256を比較結果・出自manifestへ紐づける。真の接続状態をセルの局所知覚へ渡さず、F002への電力的結線も行わない。

### A〜Fの数値合格ゲート（名目条件、すべて満たすこと）
- A：全時系列で、各セルの同条件F001半陰的Euler参照との位置と速度の絶対差はそれぞれ1e-9以下（m、m/s）。非駆動Bは静止、非結合時リンク力は0。
- B：結合中の距離誤差1e-10 m以下、速度差1e-12 m/s以下、A/B内部力の和1e-12 N以下。2kg合成質量の独立したF001型**離散参照**との各時点の位置（初期オフセットを控除）・速度の差は1e-9以下。内部力A=-0.5 N、B=+0.5 N、各誤差1e-12 N以下。
- C：等質量両側+1 N駆動なら各内部力の絶対値1e-12 N以下。合成質量の離散参照との差1e-9以下。
- D：時刻5.0 sの切断前後でx_A/x_B/v_A/v_Bは同じ数値をコピーし、4組とも完全一致。切断イベントは一回だけ。以後の各セルの位置・速度は独立のF001離散参照に対し1e-9以内。
- E：正負の対照の、初期位置に対する変位と速度の和の絶対値が1e-9以内。
- F：Bでdt=0.01/0.005/0.0025 sの**連続解析解に対する**位置・速度の絶対誤差が単調減少し、隣接する位置誤差比が既存の事前予測1.8～2.2に入ること。不正ケースは全件実行前に拒否し証拠を残す。
- 再現性：同一入力・同一コードで2回実行した際のconfig/raw CSV/SVG/比較結果のバイトとSHA256が一致。Git SHA/dirty、F003実装モジュールと実験suiteのSHA256を実行開始時に取得・保存。既存F001/F002回帰、GitHub Actions artifact、独立監査すべて合格して初めて正式採用の候補とする。

## 独立視点の設計監査による明確化（2026-10-15）

力学式は作用反作用・合成質量の運動と整合する。これは既知の理想拘束を実装する検証であり、H003a〜cの支持は新しい物理法則や自律結合の発見を意味しない。以下は実装可能な数値範囲と検証方法の補足で、A〜Fの条件・許容差を変更しない。

- **有限性の境界**：各入力が有限でも、合成質量・合計外力・内部力・重心などの派生値が浮動小数点で表現可能とは限らない。非有限の派生値や状態を正常ログに含めない。表現不能なら理由付きValueErrorで正常runの生成前に拒否する。大きな有限値の中間積だけがあふれる場合は計算順序を工夫し、表現可能な結果を維持する。名目条件以外の精度保証は追加しない。
- **時間格子**：受理した数値の十進表現を厳密な有理数として解釈し、整数倍を判定する。計算環境のDecimal精度設定によって受理結果が変わってはならない。刻みの上限はF001と同じ100万ステップ、抵抗更新はdt*gamma<=1。初期拘束は表現された位置差と長さ・初速の厳密一致を要求し、自動補正しない。
- **証拠の合否**：A〜Fの保存済みstates.csv・events.csvを読み戻し、全時系列を独立した離散更新式と照合する。Dはイベント欄内のコピー同士だけでなく、切断までの結合参照・切断後の独立参照・同時刻CSVとも比較する。EはA/B両方を検査する。記録した最大誤差を表示するだけではゲート通過としない。
- **証拠の出自**：rejections.jsonは無効入力全体（非有限値は明示した文字列表現）を保存し、比較結果からSHA256で参照する。実装モジュールが再利用するF001コードも出自に含める。比較ファイルを含むスイート全体の同条件再実行一致を確認する。

この設計ブランチのF003は引き続き未実装・未観測。後続PR #8の実装・観測記録はそのブランチで管理する。
