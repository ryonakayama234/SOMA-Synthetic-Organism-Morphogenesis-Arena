# F004 A〜F：内部駆動の仕事と残量による運動変化【未実施】

以下は**予測・比較ゲート案**であり、SOMAの実行ログではない。1D・1セル、質量1 kg、抵抗0、dt=0.1 s、総時間1.0 s、初期位置0 m／初期速度0 m/s、効率100%、初期容量1,000,000 µJとする（EのブレーキとFの境界検査を除く）。整数値はWolfram Languageの有理数反復で2026-10-15に独立に再計算した。

| 対照 | 指令／外力／初期残量 | 事前の離散予測 | 計測の意味 |
|---|---|---|---|
| A | 内部0 N／外力1 N／残高1,000,000 µJ | t=1: x=0.55 m, v=1 m/s, 残高1,000,000 µJ | 外部仕事を電池に算入しない |
| B | 内部1 N／外力0 N／残高1,000,000 µJ | t=1: x=0.55 m, v=1 m/s, 残高500,000 µJ, 10ステップ駆動 | F001運動・F002台帳が接続 |
| C | 内部1 N／外力0 N／残高0 µJ | t=1: x=0 m, v=0 m/s, 残高0 µJ | 駆動拒否 |
| D | 内部1 N／外力0 N／残高300,000 µJ | t=1: x=0.49 m, v=0.7 m/s, 残高55,000 µJ, 7ステップ駆動 | ステップ中途の不足が軌跡を変える |
| E | 初速度1 m/s、内部-1 N、外力0 N、残高1,000,000 µJ | t=1: x=0.45 m, v=0 m/s, 電池残高不変 | 理想ブレーキで回生なし（個別に検算） |
| F | dt変更、少額µJ、無効入力、再実行 | 残高非負・会計残差0、量子化差と積分誤差の記録、拒否と同一設定再現 | 境界と再現性 |

- B：10ステップの理想正仕事合計0.5 J。質量1 kg、初速0、抵抗なしの場合、台形仕事と運動エネルギー変化は一致する。
- D：7ステップの累計仕事0.245 J。8ステップ目の候補仕事0.075 Jに対し残額0.055 Jなのでそのステップでは内部力0となる。その後も内部駆動を適用できず残額55,000 µJ。
- A/Bは意図的に最終位置と速度を同値とする。**エネルギーの出所が違うこと**を記録から検証する。
- Eは負のモーター仕事を台帳へ返さない理想化した散逸ブレーキ。現実の回生制御一般の主張ではない。
- Fには正の微小仕事が1µJへ切り上がる境界、float非有限、負容量、矛盾した時間格子、強制残量超過、XML不正ID、状態非有限、保存済みCSVの改変検出を含める。具体的な入力集合を実装前に固定する。

## 保存・検証
- config.json：使った力の出所、残量・容量、刻み・初期条件、シード未使用。
- states.csv：時刻、位置、速度、指令・適用した内部力、外力、残高、候補仕事、整数費用、採用／不採用。
- ledger/events.csv：F002で受理した支出のみ。1ステップの複合動作は両状態同時に確定。
- comparison.json：A〜Fの事前予測、実測、差、全時系列の独立参照判定。
- manifest.json：Git SHA/dirty、実装と実験スイートのhash、生ログhash、seed・実行条件、CI証拠。
- motion_energy.svg：位置・速度・電池残量を対応する時間軸で見る（元データはCSV）。
