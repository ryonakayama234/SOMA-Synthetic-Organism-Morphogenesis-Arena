## Sole question and permitted claim
Under an idealized fixed-ground one-shot motor primitive, can a private-battery-feasible t=0 2D impulse move a two-disk trajectory from near-miss to continuous-TOI contact? Ground absorbs opposite impulse. This measures a **prescribed actuation's causal effect**, not autonomous intention, ecological joining, realistic traction, biological evolution, sensor use, or morphological self-assembly.

## Strict physics and input
- Exactly two named frictionless disks A/B, m=1kg, radius=.5m each, no rotation, links, resource field, transmission, communication, force after t0, torque or periodic motor. No-gravity horizontal plane; immobile ideal environment impulse sink as declared.
- Initial distance strictly >1m. All world scalars finite (not bool), position component |x|/|y|<=100m, velocity component <=100m/s, command impulse component <=0.25 N·s. Accept only restitution e=1 or 0.5. Initial A/B private balance integer in [0,1000000]µJ. Every cell nominal capacity=1000000µJ. 2.0s horizon, nine sample times k/4 for k=0,...,8. Full inputs must have exact frozen keys. Jx/Jy are researcher-prescribed, **not generated by a policy**. Explicit metadata includes version ID and world ID.
- Action phase t=0 ordered A then B *for logging only*, no physical cross-dependence. Each independent private charge computed from pre-action velocity and that cell's own J. Input numeric charge semantics **exact rational decimal** `Fraction(str(v_x))*Fraction(str(J_x)) + Fraction(str(v_y))*Fraction(str(J_y)) + (Fraction(str(J_x))**2 + Fraction(str(J_y))**2)/2` for m=1kg. `candidate_charge_uj = ceil(10^6 * max(0,W_exact))` using integer Fraction numerator/denominator, **no float comparisons or EPS near integer µJ boundaries**. If J=(0,0): idle/zero charge. If candidate charge > own balance: reject/zero J/zero charge. Else apply exactly requested J and debit candidate charge from own balance. Negative W is ideal dissipation (zero charge, no recharge). Environment receives `-ΣJ_applied` N·s.
- World velocities use binary64: accepted `v_i_after=v_i_before+J_i/m_i`. Subsequent motion uses F022.v1 adopted `soma/f022.py` **as an immutable restricted free-flight/collision solver** on a separate F023 scenario with post-action initial velocities, never mutate F022 v1 or write an F022 archive as F023 evidence. Continuous TOI and impulse/graze semantics, near-ambiguous fail-closed, 9 post-event samples as F022 frozen. At t=0 sample means **after** both action decisions. Action log carries before/after action velocities and world position.
- Momentum measured as cells plus logged external ground reaction; `P_final - P_initial + J_ground=0` (per component), with passive contact sum zero. Energy audited as `K_final - K_initial - ΣW_applied + K_collision_loss = 0`, with signed work (not billed µJ) and analytical restitution loss; rounding excess for battery separately. Each bounded scalar comparison abs error <=1e-9 * max(1,abs(reference)) in SI; event overlap<=1e-9m. Invalid/nonfinite/initial contact/bad balances/oversized impulses reject before creating primary archive. Enforce <=1 impact per world and no physical energy or momentum magic.
