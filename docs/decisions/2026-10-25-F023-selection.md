# Selecting F023 — 2026-10-25 (no protocol freeze / implementation / primary observation)

## Basis
[F022's adopted result](../../findings/F022-validation.md) supplies passive deterministic two-disk 2D TOI, but **not action or ground-referenced propulsion**. F021's double-owner private motor + energy causal infrastructure exists only in ideal 1D worlds; F020's trajectory changes were often net-energy negative. The current [research charter](../PROJECT.md) prioritizes approach, encounter, assembly and individual-level inducement over communication; [agenda](../RESEARCH_AGENDA.md) demands few assumptions and negative controls.

## Five options evaluated
| Candidate | Information gain | Confounding / dependencies | Decision |
| --- | --- | --- | --- |
| F023 2D private impulse / Active Encounter | directly tests whether one causally owned action changes missed contact; 2D encounter prerequisite | ideal ground, work quantization, event order; tractable as one-shot | **SELECT for design** |
| 2D contact-triggered mechanical attachment | differentiates contact and enduring link | requires nonpenetrating constraint and latching energy, potential torque/rotation issues | defer |
| V002 2D read-only Observatory | makes archived worlds enjoyable, reviewable, UI-panel foundation | not itself new physical action or body-formation evidence; V001 remains Draft | separate UI candidate |
| Local 2D perception + online learning | progresses towards endogenous approach | action, sensor, policy, objective and agent/world boundary arrive at once | defer |
| 2D renewable resources and ecological competition | eventually interrogates viability and join incentives | traction, harvesting, feedback, costs, attachment confounded | defer |

## Decision and boundaries
Select **one new primitive**: t=0 per-cell privately funded ground-referenced 2D impulse with opposite reaction, then F022-like passive TOI. First test whether it changes contact geometry, not whether the cell *wants* to meet. A zero-effect or rejected motor action is scientifically valid.

**Alternative decision:** if review establishes that a one-shot ideal impulse creates misleading ecological interpretation or unverifiable energy quantization, pivot to read-only V002 using only F022 frozen recordings before adding actuation; record this as an explicit next selection, not a silent F023 redesign.
