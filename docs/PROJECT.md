# 研究憲章：身体の創発を発見する

## 中心の問い
「小さな機械が何の役割も事前に割り当てられずに存在するとき、どんな物理・資源・行動条件で、結合・分離・協調・役割分化が生まれるか？」

## 研究優先順位の再確認（2026-10-21、研究者の明示的な方向修正）

**第一の問いは通信ではなく身体創発である。** はじめ互いに独立して存在し、役割を事前に割り当てられていない個体に、どのような局所的な物理・資源・行動条件なら**接近・集合・結合・維持・離脱・分裂**を選ぶ誘因が生まれるか。そして、集合の結果に、単体では得られない持続性・行為能力・機能分化が成立するか。

**第二の問いが通信である。** 身体形成・存続の構成要素として情報の伝わり方・利用の仕方が変わり、場合によっては能動的な通信が生まれるのではないか。通信は身体形成の必要条件とも、最初からの目標とも、学習に対する直接の報酬ともみなさない。

- **身体的な伝播も候補**：接触、張力、反力、変形、振動、姿勢、動作リズム、近傍での停止や故障、資源消費・共有の変化、環境に残る行動や生存の痕跡など。必ずしも1bit packet、電気的／無線通信、明示的な記号言語を経由しない。
- **現象を先に分類しない**：力学的な強制連動／環境への副産物／他個体が利用する手掛かり／他個体の反応を利用するよう獲得された送信行動は区別して観測する。物理相関だけでは「通信の創発」と判定しない。
- **研究者は信号の意味や役割を先に付与しない**。研究者が定義できるのは力学・局所センサー／作用の可用性、代謝・資源制約、選択可能な行動などの条件であり、事前に「結合が得点」「送信成功が得点」「Bは送信者」「Aは解読者」と決めない。
- **適応度の帰属に注意**：集合体の総エネルギーが増えても送信者個体に利益が戻るとは限らない。個体別・集合体別の継続性、資源収支、協調利益、衝突・負担・離脱を別々に観測する。単体のまま・結合しない・通信しない解も正当な結果。
- **因果検証**：同じ局所ルールのもとで、独立／接触のみ／結合／切断・遮断／局所伝播の除去／通信機会の変更を比較し、成果・持続性・実効的な能力と観測可能な反例を保存する。機械的な力の伝播と、受信後の能動的な行動変化も切り分ける。
- **既存研究との関係**：F014–F016の事前定義bitは、限定した情報利用の対照実験であり、身体／通信の自然発生を実証していない。独立個体の集合・維持へ研究の主軸を戻す。長期Issue [#51](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/51)を関連研究の母課題とする。新たな物理学習機構、信号API、実験結果は本方針文書では追加・主張しない。

## 研究目的
ロボットの身体を設計者が完成させるのではなく、部品間の作用から機能が生まれる条件を実験的に同定する。見慣れない形を作ること自体ではなく、その形の機能を反事実的な介入（結合を切る・モーターを止める等）で検証する。

## 研究アジェンダへの委任

研究憲章は**長期的に何を解明するか**を定める。個々の実験候補を何の理由で優先するか、存続可能性・結合の実利・身体的情報のどの未解明条件を切り分けるかは、更新可能な[研究アジェンダ](RESEARCH_AGENDA.md)で決める。これは行動距離・生存時間・結合回数を最大化する報酬の指定ではない。実験の実施と採否は従来の[研究手順](RESEARCH_PROCESS.md)で独立に扱う。

## 研究と美学
Mori3 のような機械的・無骨な外観は長期的な視覚方針。ただし、表現上の美しさを初期の物理・知能の仕様に混ぜない。

## 先に決めないこと
- 「腕」「足」「脳」「電池担当」などの生物学的／機能的役割。
- 合体が必ず得になるという報酬設計。
- 最適な結合数・身体サイズ。
- 全体構造を知っている中央司令塔。
- 2D/3D、制御学習手法、可視化エンジンの永久固定。

## 区別すべき4種の主張
- **先行研究の事実**：出典と引用先がある。
- **仮説**：まだ検証されていない予測。
- **設計上の仮定**：実験の都合で置いた条件。自然界の事実ではない。
- **観測結果**：条件・シード・コード版・ログに裏づけられた値。

## 初期の段階的問い
1. 単体セルの動きを因果的に説明できるか（F001）
2. 物理・行動と資源消費が矛盾しないか（F002）
3. 結合は何を変えるか（F003）
4. 同一セル群が環境によって異なる集合体を選ぶか（後日）
5. どのような干渉実験で未知の「器官」を発見できるか（後日）
6. 自分の構造を知らないセルが身体図式を得られるか（後日）

## 研究倫理・精度
- 「創発」や「進化」を成果の宣伝文句として先取りしない。複製・遺伝・変異・選択なしに生物学的進化が成立したとは言わない。
- 負の結果を破棄せず、生データとともに記録する。
- 再現性と仮説の反証可能性を性能より優先する。
