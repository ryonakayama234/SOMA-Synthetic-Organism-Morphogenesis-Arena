# 身体構造と通信規則の共創発 — SOMAの長期研究仮説

> **身体の創発は、必ずしも通信の創発を必要としない。しかし、身体の形成・維持に有利な情報伝達が存在する環境では、通信規則と身体構造が互いの進化・学習可能性を変化させ、共創発するのではないか？**

**状態：BACKLOG / HYPOTHESIS ONLY（2026-10-21）。** 観測済みの現象、採用済みの機能、確定したプロトコル、F016の実装仕様ではない。

## 1. 分離して扱う現象

| 現象 | 言えること | それだけでは言えないこと |
|---|---|---|
| 物理的情報伝播 | 結合・力・振動・形状の変化が隣接セルへ影響 | 専用通信・シンボルの存在 |
| 環境媒介の情報 | Aの行動が環境を変え、Bに観測可能な差ができた | AとBが合意したメッセージ意味 |
| 外部指定の情報通信 | B由来の局所情報を規定されたチャネルでAが取得 | 発信／解釈規則が創発したこと |
| 適応された通信規則 | 信号選択と受信後行動が経験・学習・選択で共適応 | 身体構造も共に創発したこと |
| 身体×通信の共創発 | トポロジーの変化が通信を変え、通信が形態・維持を因果的に変える | 生物学的な個体性・進化的転移の自動成立 |

生物学的「進化」を厳密に主張するには、複製・遺伝・変異・選択を検討する。初期のアルゴリズム最適化・学習は同一視しない。

## 2. 先行するSOMA内の証拠とその限界

[F014](../topics/F014-peer-body-observability/SPEC.md) の固定理想1D実験では、Bの局所的な移動1bitがA-onlyでは区別できない特定の観測を区別する。ただしBが別の外力で動く反例も存在し、物理的リンクの一般同定には至らない。

[F015](../topics/F015-active-body-probing/SPEC.md) の固定理想1D実験では、能動介入後、保持外力の反例は**A-onlyでも**区別でき、B bitの追加識別寄与は**ゼロ**。指令追随外力の反例は依然として観測同値となる。

どちらも、通信の**行為上の価値・正味エネルギー利益・自律的意味獲得・形態創発**を実証していない。1bitは測定ペイロードであり、source/step/timeなどを含む配送全体の情報量ではない。

## 3. 研究上の仮説と反証

**H-C1／通信は必須でない場合がある。** 局所物理／環境応答だけで目標を達成する条件を対照群として残す。通信が役立たない・有害な結果も棄却しない。

**H-C2／通信の価値は条件付き。** 情報非対称性、正の通信コスト、タスクの行為自由度、環境制約によって通信の正味便益は正にも負にもなり得る。通信メッセージの正誤そのものを唯一の目的関数にしない。

**H-C3／信号規則の意味は与えずに獲得できる可能性がある。** 送受信者の適応後、未見の環境や送り手入れ替えに対しても、信号を遮断・改変した場合に受信行動と行為成果が因果的に変わるかを調べる。意味を事前割り当てた方式は対照であって、創発の証拠ではない。

**H-C4／相互形成の可能性。** 物理的結合・配置が通信の到達性を変え、通信可能性が結合・分離・維持を変える**双方の介入効果**が出るか。単なる相関、通信だけの進化、形態だけの変化は共創発の十分条件ではない。

## 4. 研究ゲート（番号・APIは未予約）

1. **通信価値の成立性**：独立の物理的行為成果を持つ最小実験と、通信有無・ランダム化・費用差の公正な対照を定義する。
2. **符号の適応**：送信規則・受信応答を最初から命名せず、学習後の情報利用を反事実で検証する。
3. **通信とトポロジーの共変化**：接続を研究者が初期固定する実験から、環境条件での動的接続へ進む。各現象を区別する。
4. **因果的な共創発の検証**：形態だけ固定、通信だけ固定、両方可変、双方遮断などの統制群で交互作用を検査する。
5. **頑健性／再現性**：事前登録された複数環境・複数シード・負例・数値収束、研究者専用オラクル、保存ログの再生で裏づける。

この順序は**可能な研究経路**であり、実装予定・成功予測ではない。条件が満たされなければ停止・後回しにする。

## 5. F016への切り出し（ただし実装は未許可）

[F016提案 #52](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/52) の唯一の問いは次のとおり。

> セルB由来の低帯域1bit信号に正のコストがあるとき、その情報は、同じ環境に置かれたA-only系と比べ、独立の行為成果を正味で改善する条件を持つか？

**まず研究設計の成立性を調べる。** F014の「情報識別率」、F015の「応答系列の差」は、実際の行為成績と同一ではない。通信があっても行動を変える自由度のないモデルなら利益を検証できない。必要な物理的行為課題、エネルギー台帳、統制された局所知覚、送信コストを明確にするまでF016の数値実験／仕様凍結を始めない。

F007の外部有効力世界とF011–F013の内部力／地面世界を無検証に混ぜない。選んだ力学モデルの整合性を独立に監査する。研究者専用の結合真値・外力・将来情報をセルの決定器に渡さない。

### 将来の設計に関する留保

- 汎用`Packet`、`Token`、`Protocol`、`Communicator`、`BodySchema`等のAPI名やデータ構造は**未定**。発見したい現象を実装時に先取りしない。
- 最初のチャネルは、研究者定義の単純な信号でもよいが、それを「自発的通信」と呼ばない。
- 通信に発信エネルギー／受信処理／遅延・喪失があるなら、コスト会計・故障系を明示する。
- 介入：チャネル遮断、定数bit、ランダム／シャッフル、遅延、同じセンサー情報を渡す対照を事前登録。学習を使う段階ではネットワーク容量や探索予算も合わせる。
- 出力には実行設定・観測・物理的な成果・通信費・失敗・否定結果・不確実性を分けて保存する。
