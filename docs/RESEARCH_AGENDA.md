# 研究アジェンダ：何を解明する実験から始めるか

**位置付け:** [研究憲章](PROJECT.md)（何のために研究するか）と
[一機能ずつの研究手順](RESEARCH_PROCESS.md)（どのように検証・採否判断するか）
の**中間**にある、更新可能な**研究課題選定の原則**。
[長期研究課題 #51](https://github.com/ryonakayama234/SOMA-Synthetic-Organism-Morphogenesis-Arena/issues/51)を
母課題とする。本書は**研究課題選定の現行原則**として採用する。ただし、本書だけではF021以降の実装・事前登録・世界生成を承認しない。

## 1. 不変の中心課題と、研究者の仕事

独立した小さな個体が、どのような**物理・資源・行動・情報**条件のもとで、
接近、集合、結合、維持、離脱、機能分化などを可能にするのか。
その結果が個体と集合体にもたらす**新たな行為可能性・負担・持続性**は何か。
**なぜその現象が成立し、何を除去すると成立しなくなるか**を反事実的に理解する。

これは研究者の**理解したい問い**であり、個体に与える**報酬関数**でも
「必ず結合しなければならない」という期待でもない。単独維持、非結合、
離脱、活動停止、非通信、効果なし、逆効果は正当な観測結果である。

通信は身体形成を説明するための**必要に応じた候補要因**であり、
通信の存在や送信回数を目的としない。既知の外部有効力・理想剛体・研究者指定結合による
効果を「自律的身体形成」と混同しない。

## 2. 四つの層を混同しない

| 層 | 定義するもの | この層に持ち込まないもの |
|---|---|---|
| 研究目的（憲章と本書） | 何の因果関係・生成条件を知りたいか | 実験結果の望ましい符号、最適な形 |
| 環境と制約（SPEC/PLAN） | 力学、資源、コスト、センサー／行動機会、失敗条件 | 望む動きや結合を発生させるためだけの恣意的報酬 |
| 個体の行動規則（個別実験） | 利用可能な局所観測・行動・任意の学習／選択原理 | 研究者だけが知る世界真値・反事実の正解 |
| 観測・検証（findings） | 個体別・集合体別の運動、存続、資源収支、結合、反例 | 発生頻度をそのまま有益性・自律性の証明にすること |

**存続可能性 (viability)** は有力な観測・成立条件だが、
単純な「生存時間最大化」スコアと同一視しない。エネルギー、維持費、
修復、資源再生、故障などは**実装・実験した場合に限り**成立条件として扱う。
維持費を導入する場合、それが物理的構成を表す仮定か、ただの時間罰則かを明記する。
無活動が最も長く存続する世界も、無理に「動かす」ために報酬を調整しない。

## 3. 実験候補を選ぶゲート（先に反証可能性を確保する）

実験候補は下記の順で検討する。**正の効果が出そうか**を採用基準にしない。

1. **解明したい欠落**: 既存のFxxxで何がまだ因果的に説明できないか。重要な未同定・交絡は何か。
2. **最小の対比**: 一つの機構・条件を変えるだけで、対立説明を区別できるか。切断、遮断、費用変更、固定対照などがあるか。
3. **物理と個体性**: 仕事・エネルギー・力の源と作用反作用、局所観測、個体ごとの負担と利益を偽らないか。理想化は理想化としてラベル付けする。
4. **自由度と外生性**: 結合／送信／長距離移動の得点を直接設計していないか。評価指標や世界真値が個体の政策入力へ漏れないか。
5. **測定と再現性**: 陰性・逆効果・何も起きない場合を含めて記録でき、実験前固定と独立経路の監査を実施できるか。
6. **必要な追加仮定の少なさ**: 新しい行動能力や生態ルールを一度に増やしすぎないか。最大限の説明力を、必要最小限の新規仮定で得られるか。

この審査を通った複数案は、**因果的情報利得、実験の識別可能性、未検証の仮定量、負の対照の質**で比較する。
数値的な重み付けや順位は必須ではない。どの条件を満たすと選定理由が逆転するかを残す。

**作業委任の契約:** 各Issueには目的・制約・評価基準を明示するが、
局所実装には自由度を残す。重大度に応じて実装者とは別の検査経路を置く。
機能としての技術的受入と科学的仮説の支持は分ける。

## 4. 現在の候補領域（順位は暫定であり、実装順序の約束ではない）

| 優先的に解明したい不明点 | 主要な問いと反証 | 必要条件／注意 |
|---|---|---|
| **A. 存続可能な資源―行動循環の成立境界** | 取得が将来の行動を可能にしても、どの条件で資源費用を回収・再利用できるのか。無活動／資源不足／十分な初期電池では何が異なるか。 | F020の短時間・固定力・有限資源の限界を明示。維持費・再生を後付けで正結果に調整しない。存続は観測であって常にエージェント報酬ではない。 |
| **B. 独立個体にとっての接続の費用と利益** | 研究者がYYに固定しなくても、接近・接続・維持・離脱に各個体の局所的な誘因が存在し得るか。各個体の利益は一致するか。 | 最初の移動、接触成立、双方の行動権限、力の源と費用、離脱可能性を要する。総体利益だけでBの誘因を主張しない。 |
| **C. 形態が新しい機能を生む条件** | 結合構造は単なる質量効果以上に何を可能にするか。その機能はリンク切断・負荷変更で失われるか。 | 見た目、走行距離、持続時間のみでは機能創発と呼ばない。モデル間の物理的整合性を検証する。 |
| **D. 身体経由の手掛かりと能動的情報の価値** | 張力、接触、動作、資源痕跡が相手の選択に利用される条件は何か。受動的伝播と学習された発信を区別できるか。 | 情報の利用を、遮断・攪乱・遅延などの介入で区別。固定1bitの正対照と自発的信号を混同しない。 |
| **E. 開放的探索・再発明の条件（長期）** | 多様な環境・身体・行動を相互生成すると、新しい機能が継続的に現れるか。なぜ飽和／退化するか。 | 現行SOMAはopen-ended evolutionの達成を主張しない。複製・遺伝・変異・選択なしに進化と呼ばない。単なる新規性・形態数だけでは機能成立の証拠にしない。 |

**選択の方向性:** AとBの区別が現時点で有益だが、
Aを終えない限りBへ進めないという逐次ロードマップではない。
まず「Bの因果評価を誤らせるA側の未解明条件」を特定し、その最小のものを先に測る。
現実的な接触や力学がボトルネックなら、Aに先行してB/Cの基盤試験を選んでよい。
通信・信号を研究の中心目標へ自動的に昇格させない。

## 5. F020から得た、次の選定に使う知識

[F020の事前凍結と限定採用記録](../findings/F020-validation.md)では、
6,144保存ワールド、3,072対照比較のうち321件で
「実際に獲得した資源→後続のAモーター許可→軌跡変化」が観測された。
一方、その321件でA正味エネルギー差は減少263・同値36・増加22で、
Bの正味差は3,072比較すべてでゼロだった。
これは**行動可能性と存続利益が同一でない**ことを示す、固定1Dモデル内の結果である。

これらの数は32個の使い回した資源場シードの反事実比較であり、
独立な生態標本数・結合の自律選択・双方の利益ではない。
したがって、これらの正負比を将来の「期待する成功率」や報酬の調整目標にしない。

## 6. 個別実験へ引き渡す最小テンプレート

- **Unknown（未解明）**: 現在の説明で不足している条件・メカニズム。
- **Why now（優先理由）**: 既存の否定的結果／限界／モデル依存性をどう区別するか。
- **Intervention（比較介入）**: 最小の変更、固定対照、同一種／異種の条件。
- **Rivals & negatives（対立仮説・負の結果）**: 何が観測されれば別説明を支持するか。nullの保存。
- **Agency boundary（研究者と個体の境界）**: 外生設定、局所観測、政策入力、禁止する世界真値。
- **Measures（観測量）**: 個体別・集合体別の成果、コスト、継続性、行動依存性、単位と解析単位。
- **Evidence gate（採否）**: 技術的受入、科学的支持／反証／不明／未実施、独立監査、再現条件。

このテンプレートは**候補の選定用**であり、SPEC/PLANの凍結済み契約を代替しない。
Fxxx番号、パラメータ、seed、成功閾値をこの文書から一括決定しない。

## 7. 更新責任と変更の境界

- 研究者が「面白い現象」「説明したい未解明の関係」「重要な研究の方向」を判断する。
  実装担当は選定の理由と代替案を明示し、実装自由度を保つ。
- 研究憲章は原則として安定。本書は**知識の増加に合わせて改訂可能**。
  研究優先順位を変更するときは、根拠となったIssue、負の結果、反証、
  再現上の問題をPRに記録し、何を選ばなかったかも可能な範囲で残す。
- 事前登録・凍結したFxxxの条件や記録を本書の方針変更で**遡及的に変えない**。
  新しい仮説・解析は別版・別実験・追記扱いにする。
- 候補から一つを正式に選んだ後は[研究手順](RESEARCH_PROCESS.md)へ引き渡し、
  Issue→SPEC→PLAN→実装・検証→append-only findings→限定採否の順に扱う。
  本書の改訂・PRだけでは実験は開始も成功もしていない。
